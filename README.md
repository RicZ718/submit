/git init ./     把当前的项目初始化为一个git仓库

/git commit -m "<change abstract>"/    提交修改项目
/git log/       查询git的commit 记录
/git reset —hard <hash value>/     回溯到指定的commit
/git revert <hash value>/     生成一个反向提交，用来抵消历史提交
