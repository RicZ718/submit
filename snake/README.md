# 贪吃蛇（Snake）· 单文件网页游戏

一个**纯前端、无框架依赖、双击即玩**的贪吃蛇游戏，附 **Python 生成器** 与完整测试。

- 产物 `snake.html` 是一个自包含文件（HTML + CSS + JS 全部内嵌），**双击即可在浏览器打开游玩**，无需任何服务器、构建或第三方库。
- `generate_snake.py` 是生成器：运行它把配置注入并产出 `snake.html` 与可测试的 `snake_core.js`。

---

## 快速开始

1. 直接**双击 `snake.html`** 即可玩（推荐）。
2. 或重新生成（可自定义参数）：

```bash
python generate_snake.py                 # 默认配置
python generate_snake.py --cols 25 --target 200 --mines 5 --lives 4
```

### 玩法与操作

| 操作 | 说明 |
| --- | --- |
| 难度下拉 | 开局前选：简单 / 普通 / 困难 / 无尽 |
| 操控下拉 | 键盘 / 鼠标（鼠标模式下蛇会朝光标方向移动） |
| 方向键 / WASD | 移动（键盘模式；支持转向缓冲，禁止直接掉头） |
| 鼠标移动 | 鼠标模式：蛇朝光标方向移动；点击棋盘开局 |
| 🤖 AI 演示按钮 | 自动在无尽模式连吃 20 个食物（全程无需操作） |
| 空格 | 暂停 / 继续 |
| Enter | 开局 / 重新开始 |
| 吃到食物 | 得分 +10，身体变长 |
| 踩到雷 | 扣 1 条命（短暂无敌），雷消失；命用完判负 |
| 撞墙 / 咬到自己 | 立即判负 |
| 达到目标分 | 通关胜利（各难度目标不同，见下表） |

**难度对照**（尺寸相对「简单」20×20）：

| 难度 | 地图 | 雷 | 胜利条件 |
| --- | --- | --- | --- |
| 简单 | 20×20（基线） | 3 | 100 分 |
| 普通 | 40×20（2 倍，长方形） | 20 | 250 分 |
| 困难 | 40×20（2 倍，长方形） | 50 | 1000 分 |
| 无尽 | 40×30（3 倍，长方形） | 50（吃食物后重新随机分布） | 无（分数无限累加） |

界面上实时显示：**得分、最高分、局数、步数、剩余雷数、生命、目标进度条**。

## 实现说明

### 阶段一：能直接上手玩的核心游戏（需求 1–4）

**实现方式**

1. 采用「网格 + 离散状态迁移」的经典模型：蛇由头到尾的坐标数组表示，每次 `tick` 前进一格。核心逻辑收敛成纯函数 `createState / setDirection / tick`，与渲染完全解耦（这部分被抽出成 `snake_core.js`，可被浏览器和 Node 复用）。
2. 手感：`setDirection` 维护一个最多 2 步的转向缓冲队列，禁止反向与超量堆积，快速连按也不会丢方向；`tick` 间隔随得分线性缩短（140ms → 70ms），难度递进；渲染层用 `requestAnimationFrame` 在两帧间对蛇身做插值，视觉平滑不卡顿。
3. 规则：撞墙、咬到自己判负；吃到食物加分变长；达到目标分（默认 100）判胜；踩雷扣命、命用完判负——胜负/通关判定齐全。
4. 界面：Canvas 绘制棋盘/蛇/食物/雷；覆盖层在「开局/暂停/胜负」时给出明确提示；状态栏常驻显示得分、步数、剩余雷数、生命等。

**验证方式**

- `tests/test_logic.js` 对移动、吃食物、撞墙、自咬、踩雷、通关、反向缓冲等做单元断言（全部通过）。
- `tests/test_logic.js` 的无头启动冒烟测试在模拟浏览器环境真实执行主脚本，确认能正常启动。
- 手动验收：双击 `snake.html`，方向键移动顺畅、吃到食物变长、撞墙/自咬结束、到 100 分通关。

### 阶段二：计分 / 主题 / 战绩等增强功能（需求 5–7）

**实现方式**

1. 计分制与持久化：`localStorage` 存 `snake_high`（最高分）、`snake_games`（局数）；`onGameEnd` 在每局结束时更新两者并追加历史。`新一局` 只重开当前局、不清零；`重置记录` 带确认弹窗，清空三项持久化数据。
2. 主题切换：深浅两套配色用 CSS 变量（`:root` 深色默认、`[data-theme="light"]` 浅色）表达；点按钮切换 `document.documentElement` 的 `data-theme` 即时生效；`<head>` 里的内联脚本在首帧渲染前读取 `snake_theme` 恢复主题，刷新不丢、也无闪烁。
3. 战绩记录：`snake_history` 存 JSON 数组，每局结束 `unshift` 一条 `{胜负, 得分, 步数, 时间}` 并截断到 10 条；「历史记录」按钮打开弹窗展示完整列表。

**验证方式**

- `tests/test_generator.py` 断言生成的 HTML 包含 `localStorage`、`snake_theme`、`snake_high`、`snake_history`、`data-theme` 及「最高分/局数/重置/历史/主题」等关键文案与标记。
- `tests/test_logic.js` 覆盖自定义配置注入（含 `maxMines`/`maxLives`/`target`），验证计分/通关/踩雷扣命逻辑。
- 手动验收：玩两局确认局数 +2、历史追加两条；刷新页面确认最高分/局数/主题保留；点「重置记录」确认清空；切主题即时生效且刷新后保持。

### 第二轮迭代：难度 / 鼠标操控 / bug 修复

**实现方式**

1. 四档难度：核心里定义 `DIFFICULTIES`（easy 取生成器基线，normal/hard/endless 为固定矩形地图与雷数/目标）；开局前用下拉选择，切换即 `newGame(false)` 进入待开始状态。无尽模式 `target=null`（不设胜利分）且 `reshuffleMines=true`。
2. 可达性保证（「不能产生赢不了的雷分布」）：新增 BFS `reachable(state, from, to, mines)`；`placeFood` 只把食物放在「从蛇头可达」的空格，`placeMines/reshuffleMines` 在放雷后校验食物仍可达、否则重试（上限 60 次）。同时雷不落在蛇身/食物/蛇头四邻，避免贴脸刷雷与封死食物。
3. 无尽模式刷新：吃到食物后 `reshuffleMines(state, maxMines)` 丢弃旧雷、重新随机分布满 50 颗，并保持可达性。
4. bug 修复：`keydown` 里删除「方向键 / 空格在胜负后触发 `newGame`」的逻辑，胜负后只有 `Enter` 与「新一局」按钮能重开。
5. 鼠标操控：新增操控方式下拉；鼠标模式下用 `core.steerToward(head, 光标网格坐标)` 每帧给出「朝光标、且不反向」的方向（反向目标自动退化为垂直方向），点击棋盘开局。

**验证方式**

- `tests/test_logic.js` 新增：难度表数值、四档初始布局「食物可达 + 雷不贴脸 + 不重叠」、`reachable` 隔断识别、无尽模式刷新不胜利、`steerToward` 不反向（共 20 项通过）。
- `tests/test_generator.py` 新增难度/操控/鼠标相关标记断言（共 8 项通过）。
- 无头启动测试通过 `SnakeApp` 钩子验证：难度切换后地图/雷/目标正确、操控方式切换正确、以及「胜负后方向键/空格不重开、Enter 重开」。
- 手动验收：开局选「困难」看到 40×20 与 50 雷；选「无尽」得分无上限、吃食物雷重排；鼠标模式下移动光标蛇随之转向；游戏结束后乱按方向键不会重开。

### 第三轮迭代：AI 自动演示（无尽模式连吃 20 食物）

**实现方式**

1. 核心 AI：新增纯函数 `autoMove(state)`，返回下一步方向。算法分三层：
   - 用 BFS 求「从蛇头到食物」的最短路径，取第一步方向；仅当该步「安全」时采用（`isSafeMove`：不撞墙/雷/自身，且走完后蛇头仍能 BFS 回到尾巴，避免被逼死）。
   - 食物不可达或路径不安全时，在安全方向里选「可活动空间最大」者绕行（远离死角、等待机会）。
   - 兜底：不做安全校验、向可活动空间最大处走。
2. 死局根治（配合可达性保证）：`placeFood` 只把食物放在**不贴墙 + 周围 1 格无雷**且从蛇头可达的格子；`placeMines/reshuffleMines` 也用 `blockNearFood` 排除食物 3×3 邻域。这样雷永远无法把食物围死。
3. UI 演示：新增「🤖 AI 演示」按钮与演示横幅；点击后强制切到无尽模式、`newGame` 开局并进入 `demoMode`，循环里每 tick 用 `autoMove` 自动转向；连吃满 `DEMO_FOODS=20` 个食物后停止并显示「AI 演示完成」；演示期间忽略键盘/鼠标干扰，且不计入最高分/局数/历史。

**验证方式**

- 单元测试：`autoMove` 朝食物方向、避雷；`tests/test_logic.js` 里用真实 `tick` 循环跑「无尽模式连吃 20 食物不死」3 次断言。
- 离线稳定性：额外用脚本对「40×30 / 50 雷 / 连吃 20 食物」跑 **500 次，500/500 全部成功**（无死亡、无卡死、零踩雷）。
- 无头启动：通过 `SnakeApp.startDemo()` 断言进入演示模式、切到无尽难度、地图 40×30。
- 手动验收：点「🤖 AI 演示」，观察蛇自动追食物、绕过雷、连吃 20 个后弹出完成提示。

## 技术要点与设计决策

- **为什么是 HTML 而不是 Python 直接跑**：需求 4 要求「纯前端单文件、浏览器双击打开」，只有 HTML/CSS/JS 能满足；Python 作为**生成器**介入，兼顾「用 Python 生成」的字面要求。
- **核心逻辑与渲染解耦**：逻辑是纯函数（可单测、确定性可推导），渲染/输入/持久化是副作用层；这样 `snake_core.js` 能被 Node 直接 `require` 做单测，也能被浏览器内联使用，一份代码两处复用。
- **持久化键**：`snake_theme`、`snake_high`、`snake_games`、`snake_history`，全部走 `localStorage`，跨刷新保留。
- **无依赖**：不引任何框架；测试仅用语言内置能力（`unittest` / `assert` / `vm` / `fs`）。
